it makes use of both rto and fast retransmit. if the packet loss detection is triggered by 3 duplicate acknowledgements then it is a fast retransmit algorithm in action. on packet loss detection through fast restransmit, cwnd is reduced by 50%, 2 duplicate acks are received that means network is performing well because acks are being received which means packets are getting delivered to the receiver. so, cwnd is reduced by 50% in order to allow the network to comet out of congested state. on packet loss detection through RTO, reset cwnd to initcwnd. if the rto timer expires that means the network is badly congested. so the cwnd has to be reduced to the initial value in order to recover the network from congestion
