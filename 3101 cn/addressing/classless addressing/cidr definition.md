cidr, or classless inter domain routing, is a networking technique introduced to overcome the limitations of traditional ip addressing system, which was based on classes. cidr allows more flexible allocation of ip addresses by eliminating strict class based divisions.

classless inter domain routing is a method of ip address allocation and ip routing that allows for more efficient use of ip addresses. cidr is based on the idea that ip addresses can be allocated and routed based on their network prefix rather than their class, which was the traditional way of ip address allocation.
cidr addresses are represented using a slash notation, which specifies the number of bits in the network prefix. for example, and ip address of 192.168.1.0 with a prefix length of 24 would be represented as 192.168.1.0/24. this notation indicates that 24 bits of the ip address are the network prefix and the remaining 8 bits are the host identifier.
