to reduce the wastage of ip addresses in a block, we use subnetting. what we do is that we use host id bits as net id bits of a classful ip address. we give the ip address and define the number of bits for mask along with it (usully followed by a `/` symbol), like `192.168.1.1/28`. here, subnet mask is found by putting the given number of bits out of 32 as 1, like in the given addresss, we need to put 28 out of 32 bits as 1 and the rest as 0, and so, the subnet mask would be `255.255.255.240`. a classless addressing system or classless interdomain routing (cidr) is an improved ip addressing system. in a classless addressing system the block of ip adderss is assigned dynamically based on specific rules.
