to access the internet, one public ip address is needed, but we can use a private ip address in our private network. the idea of nat is to allow multiple devices to access the internet through a single public address. to achieve this, the translation of a private ip address to a public ip address is required.
network address translation is a process in which one or more local ip address is translated into one or more global ip address and vice versa in order to provide internet access to the local hosts. also, it does the translation f port numbers i.e. masks the port number of the host with another port number, in the packet that will be routed to the destination. it then makes the corresponding entries of ip address and port number in the nat table. nat generally operates on a router or firewall.
