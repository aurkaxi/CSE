generally, the border router is configured for nat i.e. the router which has one interface in the local inside network and one interface in the global network. when a packet traverse outside the local inside network, then nat converts that local private ip address to a global public ip address. when a packet enters the local network, the global public ip address is converted to a local private ip address. 
if nat runs out of addresses, i.e. no address is left in the pool configured then the packets will be dropped and an internet control message protocol host unreachable packet to the destination is sent.
