1. if input condition is a range of values bounded by a and b, test cases should be designed with values a and b as well as just above and just below a and b
2. if input condition is a number of values, test cases should be designed with the maximum and minimum values. just above and just below the maximum and minimum are also considered
3. apply 1 and 2 for output domain
4. if internal data structures have boundaries like array with highest limit 100, test cases should design to exercise the data structure at its boundary
