1. unit testing: initially, tests are component individually, ensuring that it functions properly as a unit. it uses white box testing, exercise specific paths of modules control structure for complete coverage and maximum error detection
2. integration testing: handles issues associated with dual problems of verification and program construction. it uses black box test mostly, a limited amount of white box testing is used for major control paths
3. validation tests: higher order tests for validation criteria, provides final assurance that the software meets all functional, behavioral and performance requirements. black box test is used exclusively
4. the last higher order test fall outside the boundary of sw engineering. completed sw working with other components
