|            | White box (structural)                                                                                                                | Black box (functional)                                                                                                                  |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| Basis      | Internal workings, code and procedural design                                                                                         | Specified function, with no knowledge of the code                                                                                       |
| Goal       | Check that all internal operations perform according to specification                                                                 | Check that each function is fully operational and find errors in it                                                                     |
| Tests      | All independent paths executed at least once; both true and false sides of decisions; loops at their limits; internal data structures | Incorrect or missing functions; interface errors; data structure or database errors; performance, initialization and termination errors |
| Applied at | Unit testing mostly                                                                                                                   | Software interface, mainly integration and validation testing                                                                           |
| Techniques | Basis path, condition and loop testing                                                                                                | Graph-based testing, equivalence partitioning, boundary value analysis, orthogonal array testing                                        |
| Done by    | Team: manager, design engineer, programmer, tester, keeper, author, user                                                              | Independent testers                                                                                                                     |
