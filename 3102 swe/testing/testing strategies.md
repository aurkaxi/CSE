1. functional testing: mainly black box, goal is to find divergence between the specification, a precise description of the design and the coded product. specification and boundary values are analyzed 
2. system testing: an element of larger computer based system. this test s are done in the environment for which the program is design for, like a multi user network
3. recovery testing: this test forces the system to fail in a variety of ways and verifies that recovery is properly performed
4. security testing: to verify that the protection system built in the system really protect it from improper penetration
5. performance testing: test is designed to test the runtime performance of the software and occur throughout all the steps of testing 
6. stress testing: test to ensure that whether the system can handle huge amount of data, a variation is called sensitivity test
